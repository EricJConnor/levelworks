# LevelWorks Facebook groups tracker

Its own file, never mixed with the isms sheet. Updated from Muse's tables and Cowork's end-of-day
table. Group code = `utm_campaign` for that group, assigned once, never reused.

## Rules of the routine (fixed)

10 posts and 20 joins a day, 20 minutes between posts, stop at 9 pm ET, read each group's rules,
rotate the four post versions, reply to every comment the same day, any Facebook warning stops the
day. Nothing new posts without Eric's go the first time.
